# Changelog

## 0.1.0 - 2026-07-29

- Added modular Core, Input System, Camera, Animation, and Editor assemblies.
- Added manual ownership handoff, configurable command sources, non-allocating camera collision, locomotion cadence/layer blending, and prioritized animation extension hooks.
- Added optional Humanoid upper-body aim with torso/root yaw policy, visual pitch
  limits, ordered body/hands IK passes, and cached one-/two-handed weapon bindings.
- Added an idempotent consumer-owned Animator builder, Basic Character sample, EditMode tests, PlayMode tests, API documentation, and migration guidance.
